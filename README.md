# Edu-Path 🎓

Edu-Path is an AI-powered education and career guidance platform designed to help students discover educational opportunities, scholarships, exams, colleges, jobs, and suitable career pathways.

## 🚀 Features

- 🎓 College information
- 📚 Higher studies guidance
- 📝 Exam details
- 💰 Scholarship information
- 💼 Job opportunities
- 🤖 AI Assistant
- 📅 Important dates
- 🎯 Eligibility information
- 📖 What to study guidance
- 👤 Student profile and saved options

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
